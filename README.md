**Áreas de Enfoque:**

*   **Análisis de Datos:** Transformación de datos en valor mediante pipelines ETL y visualizaciones estratégicas.
*   **Soporte TI:** Mantenimiento de infraestructura, administración de sistemas Linux y resolución eficiente de incidencias técnicas.
